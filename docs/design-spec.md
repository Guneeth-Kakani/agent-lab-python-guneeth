# Soc Ops - Cinematic Design Spec

## Vision
Transform Social Bingo into a cinematic experience evoking film noir and Hollywood productions. Dark, moody atmosphere with dramatic lighting, elegant typography, and theatrical animations.

## Color Palette
- **Primary Background**: Deep charcoal (#1a1a1a) to pitch black (#000000) gradients
- **Accent Colors**: Crimson red (#dc2626), gold (#fbbf24), deep purple (#7c3aed)
- **Text**: Off-white (#f8fafc) for primary, muted gold (#fbbf24) for highlights
- **Highlights**: Neon cyan (#06b6d4) for interactive elements
- **Shadows**: Multiple layered shadows for depth

## Typography
- **Primary Font**: Cinzel (serif) for titles - evokes classic Hollywood posters
- **Secondary Font**: Orbitron (monospace) for game elements - futuristic, cinematic
- **Body Font**: Source Serif Pro - elegant and readable

## Layout Structure

### Start Screen
- Full-screen cinematic backdrop with gradient overlay
- Centered content with dramatic fade-in animation
- Title with glowing text effect
- Instructions in elegant card with subtle shadow
- Start button with pulsing glow effect

### Game Screen
- Dark header with subtle gradient
- Instructions with typewriter effect
- Bingo board as dramatic reveal grid
- Winning squares with spotlight effect
- Victory modal with theatrical entrance

## Animations & Effects

### Page Transitions
- Fade-in with staggered elements (0.2s delays)
- Slide-up reveals for content blocks

### Interactive Elements
- Hover: Subtle glow and scale transform
- Click: Ripple effect with sound-like feedback
- Marked squares: Dramatic flip animation with checkmark reveal

### Bingo Board
- Grid appears with cascading reveal (row by row)
- Winning lines: Animated highlight sweep
- Free space: Pulsing golden glow

### Victory State
- Screen-wide confetti effect
- Modal entrance with zoom and rotate
- Text animations: Letter-by-letter reveal

## Technical Implementation

### CSS Enhancements
- Custom gradients and shadows
- Keyframe animations for reveals
- CSS variables for consistent theming
- Layered backgrounds for depth

### Font Loading
- Google Fonts: Cinzel, Orbitron, Source Serif Pro
- Fallback fonts for reliability

### Responsive Design
- Maintain cinematic feel on mobile
- Scale effects appropriately
- Touch-friendly interactions

## Design Principles
- **Immersion**: Every element contributes to the cinematic atmosphere
- **Drama**: Use timing and effects to create tension and release
- **Elegance**: Sophisticated without being flashy
- **Accessibility**: High contrast, readable fonts, clear interactions
